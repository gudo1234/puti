## Vista rápida
- Administración de grupos con controles claros.
- Bienvenidas, despedidas y alertas automáticas.
- Sistema de plugins extensible y modular.
- Respuestas rápidas y utilidades diarias.

## Requisitos
- Node.js 18+
- npm o yarn

## Instalación
```bash
npm install
```

## Uso
```bash
npm start
```

## Configuración
Edita `config.js` para ajustar propietarios, textos, enlaces y preferencias del bot.

## Estructura
```
bo/
├─ main.js        # arranque del bot
├─ handler.js     # enrutamiento y permisos
├─ lib/           # utilidades compartidas
└─ plugins/       # comandos y eventos
```

## Notas
- Ejecuta en entorno estable y mantén tus credenciales seguras.
- Revisa los plugins antes de habilitarlos en producción.
